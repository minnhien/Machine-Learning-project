# Machine Learning Project — MONK & ML-CUP 2025

## Overview

This repository contains my Machine Learning project for Master’s program in Data Science and Business Informatics at the University of Pisa.

The project is an extensive experimental comparison of different ML models and Neural Network implementations on two benchmarks: the **MONK classification datasets** and the **ML-CUP 2025 regression task**.

The work covers a complete ML workflow: data preprocessing, exploratory analysis, feature transformation, model training, hyperparameter tuning, cross-validation, model selection, performance evaluation, and final prediction generation for a blind test set.
